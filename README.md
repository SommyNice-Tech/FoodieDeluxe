# FoodieDeluxe
🍔 Food E-Commerce Website

A modern, responsive, and interactive Food E-Commerce Website built using HTML5, CSS3, and Vanilla JavaScript (ES6+).

This project is part of my JavaScript learning journey. Instead of jumping directly into frameworks, I am building real-world applications with vanilla JavaScript to strengthen my understanding of core web development concepts before moving on to React.

📖 Project Overview

The application simulates a real-world online food ordering platform where users can browse meals, search for food, manage a shopping cart, save favorite meals, and complete a checkout process.

All application logic is built using JavaScript, while browser storage is used to simulate backend functionality.
